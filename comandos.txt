Instalar Prisma

comandos: 
    npm i -D prisma : Es el CLI (herramienta de comandos)
    para generar el cliente,migraciones,visor de datos
    npm i @prisma/client : es la libreria que el codigo en produccion realmente
    importa

    npx prisma init

    iniciar migraciones:
    npx prisma migrate dev --name init
    crear cliente prisma:
    npx prisma generate
    

    --para usar ES y no Commonjs
    npm i -D tsx

    ademas configirar el generate client en schema.prisma
    generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
  moduleFormat = "esm"
  generatedFileExtension = "ts"
  importFileExtension = "ts"
}

adaptador postrgress.
npm i @prisma/adapter-pg
